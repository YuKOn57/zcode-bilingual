# zcode-bilingual v0.4.2

ZCode 桌面版界面悬停翻译：英文界面鼠标悬停出中文，中文界面悬停出英文。**原有文字与排版一个字符都不改**。

## 本版亮点（v0.4.2）

- **版本免疫**：ZCode 升级整体替换 app.asar 会冲掉补丁——本插件通过 常驻自愈哨兵 + 会话/提交双 hook + 登录兜底 三层机制，在你完全退出 ZCode 后自动重打补丁并重新打开，无需任何手动操作。
- **换构建不崩**：补丁函数改为按当前构建的压缩标识符动态重建（map/snap 分名），未来 ZCode 改名不再产生引用未定义变量的代码。
- **目录免疫**：渲染树（/out/renderer/）若被 ZCode 改名/搬移，自动回退到全归档扫描定位 i18n 目标。
- **codeStale**：补丁器/词典升级后自动检测并重烤进 asar（此前只认词典哈希）。
- **一键完美卸载**：卸载时先停自愈 worker（防止还原后被重新打回）、移除登录兜底 .vbs、逐字节校验还原、注销插件、清理全部残留。
- **词典 739 条**：官方市场 40 插件 + 本机已装插件的技能/子智能体/命令描述全量覆盖，双扫描器 0 缺口。

## 稳定性（实测）

| 项目 | 结果 |
|---|---|
| 内存泄露（60s 病态 churn，60.8 万条 mutation） | post-GC 堆回落 −0.08 MB，PASS |
| 卡死 / 主线程占用 | helper 占比 2.3%（预算 ~2.2%），walk 深度封顶 60，PASS |
| 启动变慢 | hooks 170–469ms（预算 3000ms）；词典注入 ~1ms；chunk 通过 ESM 语法检查，PASS |
| 闪退 | 打补丁后逐字节验证 + 失败自动还原备份 + EBUSY 保护，PASS |
| 泄露 API key | 插件**零网络出口**（无任何 http/ws 客户端代码），结构上不可能外泄，PASS |

## 安装 / 卸载

- 一键安装：解压后双击 **安装.cmd**（完全退出 ZCode 含托盘；找不到 app.asar 可把它拖到图标上）。
- 一键卸载：双击 **卸载.cmd**——还原原版界面（逐字节校验）、注销插件、删除备份/状态/插件副本/登录兜底，无残留。
- 升级后失效？不用管：下次打开 ZCode 会自动修复；或双击 **修复.cmd**。
